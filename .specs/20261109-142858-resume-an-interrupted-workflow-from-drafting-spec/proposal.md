# Restart an existing spec

## Problem

Maestro cannot activate an existing spec to restart its workflow.

## Goal and scope

Restart the same spec from `drafting-spec`, review its documents with the owner, and obtain renewed approval before normal execution.

## Out of scope

1. Resume the interrupted agent or recover its conversation.
2. Reconstruct progress from the previous workflow phase or reconcile partial saves.
3. Delete existing handoffs or roll back product changes.

## Required behavior

See [spec.md](spec.md).
