# 20261118-211851-clear-agent-model-selections-without-losing-other-roles: Clear agent model selections without losing other roles

## Problem

The owner can replace a model in Maestro's agent menu but cannot clear it. Clearing the Builder should allow spec-only use without losing the other roles' selections.

## Goal and scope

Let the owner clear any role during initial setup or when editing agent models before starting a workflow. Keep the other selections when switching to spec-only.

## Out of scope

Changing models during an active workflow, running roles without a Builder, and adding a separate enable/disable control.
