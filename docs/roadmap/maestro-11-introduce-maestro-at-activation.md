## Objective

Introduce `Maestro` at activation and make its documentation available on demand.

See the
[specification](https://github.com/emilioSp/pi-maestro/blob/839ab9eb9753df22804d750657a616a9959c2c47/.specs/20261013-171954-introduce-maestro-at-activation/spec.md).

## Completed When

- Successful activation introduces `Maestro` and invites the `owner` to ask how it works.
- The notice retains configured agent details without adding session history or starting a model request.
- Active instructions identify the installed README and documentation paths. Their contents are read only when needed.
