# Roadmap

This roadmap is the source of truth for planned outcomes and recorded completion. Roadmap entries are not permission to implement them. The `owner` selects work and
approves its `specification` before implementation starts. Backlog items have no agreed order or date. The `owner` approves priority and scope changes.

Completed items describe their original goals and completion conditions, which may refer to behavior later changed.
