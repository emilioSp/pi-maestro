# Mission

`Maestro` uses spec-driven development to improve quality when coding with agents. It guides the `owner` to define requirements and think through a feature before writing code.
It provides a clear path from an approved `spec` to verified code and manages agent coordination for the `owner`.

The `owner` remains responsible for final code review, pull requests, and merging. The `owner` also provides and maintains the project's development checks and instructions, including linters, tests, anti-slop checks, and `AGENTS.md`.
`Maestro` and its agents use these checks and instructions.
